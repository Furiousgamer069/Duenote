# DueNote: 90-second demo script

**Before you start:** app open at http://localhost:8501, sidebar on **🧪 Demo**, shop name "Bismillah General Store". Say clearly that this is **sample replay**, not live AI.

| Time | Do | Say |
|---|---|---|
| 0:00–0:12 | Show the app title | "Every general store in Faisalabad runs on a paper khata. Owners lose track of who owes what, and asking for money is awkward. DueNote fixes that." |
| 0:12–0:25 | **Capture** → *Sample replay: Urdu table* → *Replay verified transcription* | "This is a sample Urdu page. For a reliable demo I'm replaying a verified transcription. The live Gemma 4 button reads any photo, but it takes a minute or two." |
| 0:25–0:45 | **Review**: point at the photo and the rows side by side | "Every row is checked against the photo. Names stay in Urdu script. Anything unreadable stays orange and is never counted as zero. The page wrote 14,700, and Python calculated 14,700. Green means they match." |
| 0:45–0:52 | Click **Confirm page** | "Only the owner can confirm. Nothing reaches the ledger without that." |
| 0:52–1:05 | **Collect**: point at **Rs. 14,700**; open عثمان (Usman), Rs. 4,000 → *Prepare draft* | "The reminder is a respectful template. Code inserts the exact amount, not the AI." |
| 1:05–1:20 | In عثمان's card: *Record payment* **1,000** → click | "Usman paid 1,000. Balance is now 3,000 and the total is **13,700**. And look: the old 4,000 draft is gone, so we can never ask for the wrong amount." |
| 1:20–1:30 | **History** tab | "Every confirmed page and payment is recorded and exportable to Excel. Gemma 4 transcribes, Python calculates, and the owner decides. It's open source and comes with an agent skill." |

**If asked "is that live?":** "That was the verified replay. Here's live:" then click *Read with Gemma 4* on the Roman Urdu sample (1–3 min; talk about the design rules while it runs).
